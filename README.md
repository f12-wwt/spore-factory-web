# 孢子工厂冒险 (Spore Factory Odyssey)

根据《GDD_孢子工厂冒险.md》（v0.3-web-ai）实现的可玩验证版：**吃 → 长 → 编辑 → 推进纪元**。

技术栈：Vite 8 + TypeScript + Phaser 3 + 原生 DOM UI，数据驱动（五张 JSON 配置表），本地 localStorage 存档，GitHub Pages 自动部署。

## 一键启动

线上版本：https://f12-wwt.github.io/spore-factory-web/ （推送 `main` 后由 GitHub Actions 自动构建部署）

本地开发：

```bash
npm install        # 仅首次
npm run dev        # 开发模式 http://localhost:5173
npm test           # Vitest 单测（160 项，含 5 项安全回归：存档污染 / HTML 转义）
npm run lint       # Biome 静态检查（src + tests，零告警）
npm run build      # 生产构建 → dist/（注入 CSP meta；Phaser 独立分包）
npm run preview    # 预览生产构建
```

## 范围与系统（对照 GDD）

- **三纪元**：太古宙 → 元古宙 → 寒武纪；灾害 3 种（海底热泉 / 大氧化 / 海洋酸化，预警→爆发→恢复）
- **八大系统**（GDD 4.2 架构）：Metabolism / Memory / Sensory / Logistics / Stage(纪元) / Combat / Save + EventBus 集中事件
- **数据驱动**：`src/data/` 五张 JSON 表（modules / eras / disasters / species / zones），调参不改代码
- **代谢双轨**（GDD 3.2）：E变化 = P − BMR − 移动 − 感知 − R；代谢压力 = R/P，四档压力表（80%/95%/100% 阈值：效率 85%/60%/30%，充能 -30%/-70%/停止）
- **体积机制（v0.4/v0.5）**：体积 = 4 + 已安装器官体积，**不随进食/时间自然增长**（进食溢出只进生长储备）；**体积上限 = 纪元上限（14/26/60）+ 强化加成 + 进化跳档**——防御/躯干类强化每级 **+1 体积上限**（强化细胞壁/骨骼 = 扩仓），纪元过渡自动跳档（14→26→60）。开局为**草履虫级先天器官**（细胞质/细胞膜/细胞核/口沟/胞肛）= **10/14**，留 4 点改造空间
- **孢子式编辑器界面**：左=组件库（图标格 + 悬浮提示，未来纪元显示 ❓/锁定）· 中=程序化生物预览（体积定体型、器官定外观：尾/刺/甲/眼/口/核心，带轻动画）· 右=当前属性（相对已保存状态显示 ▲▼ 增减）+ 选中组件的属性与 安装/卸载/强化 操作
- **生物编辑器**：形态模块（安装扣生长储备，卸载返还 30%，同类可叠加）+ **分层物流系统**（消化/循环/神经/运动四层，随纪元逐层解锁；安装带节点的器官**自动接入所属层**，玩家只加支线/扩容/拆除；吞吐=最宽路径、瓶颈橙色高亮、扩容费随管长、每节点 ≤4 线）
- **代谢压力口径正确（v0.5 关键修复）**：`压力 = 总消耗 / 产出`，其中总消耗 = **BMR + 移动 + 感知 + 器官常驻**（此前只算器官常驻，导致 HUD 显示 15%「健康」而实际饿死的假象——BMR 随体积线性增长却完全不进压力表）
- **消化吞吐 = min(管线最宽路径, 节点自身处理量)**（v0.5）：强化口器/胃/池提高 `nodeRate` 即真实提升吞吐；产线任一环节处理量不足都会成为瓶颈。产出 `P = (2.0 + 吞吐×0.8) × (1 + 强化%)`，正常形态压力 41~89%，强化代谢器官后回落至 36~38%，贪装器官才会爆红——强化有明确出路
- **代谢不出死路（v0.5）**：① 胃满不再堵死——溢出部分按消化效率即时折算成能量（蛋白质掉落物同样不浪费）；② **消化速率 = 基准 + 处理容量 × 0.25**（装原始胃/心泵/鳃 = 胃排空更快）；③ **代谢类器官强化 = 产出百分比加成**（每级 **+12%**，乘算：`P = (基础+吞吐) × (1+强化%)`，GDD 2.3 百分比语义），这是常驻消耗 R 上涨的对冲通路——编辑器右栏可实时看到「代谢产出 P（含强化%）/ 常驻消耗 R / 胃容量 / 消化速率 / 器官效率% / 代谢压力」；HUD 直接显示 `代谢压力 83% · 器官效率 85%`
- **先天器官（v0.5）**：细胞质/细胞膜/细胞核/口沟/胞肛 与生俱来（🧬 标记，可强化不可卸载），在形态页有专属外观（细胞膜薄膜、口沟+纤毛、细胞核核仁、胞肛出口），并自带物流节点
- **接触判定与可见体型一致（v0.5）**：进食/撕咬半径统一走 `playerRadius(bodyVol)`，杜绝"看着碰到了却没吃到"；口沟等先天口器计入摄食范围
- **孢子式纪元推进**：里程碑达成自动弹出编辑器并解锁下一纪元模块库；装上 🎯 关键模块（多细胞聚合 / 外骨骼）保存即进纪元；不装则留守本纪元（**已装模块全部保留**），下次再装关键模块即可
- **血统继承**（GDD 3.6）：纪元过渡 = 记忆100%/网络80%/体积60%/储备50%；死亡血统延续（快照入库，记忆 60% 遗传给下一代）
- **多条件里程碑**（GDD 3.7）：存活时长 / 能量 / 记忆种数 / 食物种数 / 捕食种数 / 体积 / 指定模块 / 灾害幸存
- **认知记忆**（GDD 3.5）：未知生物显示 ？？？；进食/攻击/观察后解锁图鉴；部分模块需对应物种认知才能安装（🔎 光合器/尖牙/三叶虫甲片）
- **战斗**（GDD 3.8）：生命 = 30 + 体积×6+躯干加成；护甲减伤 = 护甲/(护甲+50)；AI 状态机（巡逻/觅食/逃跑/攻击）
- **埋点验证**（GDD T16 / 文件 8）：首次编辑、首次纪元过渡、代谢崩溃率、编辑频率、核心闭环完成率、FPS —— 死亡/通关结算面板直接展示

## 开局设置

菜单「开始进化」与死亡结算「以子代重启」都会先进入**初始状态配置**：四档难度预设（温和/标准/恶劣/大灭绝）+ 六项滑杆——食物密度、灾害频率、敌对生物密度、敌对生物强度、生长速度、初始生长储备。设置跨代保留，可随时调整。

**捕食者行为**：索敌范围有限（约 170px），追击超过 6 秒或目标拉开 340px 即放弃，并进入数秒平静冷却——拉开距离就能脱战。

**蛋白质掉落**：击杀敌对或中立生物会掉落 🥩 蛋白质（粉红肉块，存留 22 秒），接触拾取直接转化**大量能量 + 爆发储能 + 消化原料**（不经过消化道），猎物营养越高收益越大。

**模块=有无，强化=上限**：安装模块即获得基础属性；强化（⬆，Lv5 封顶）决定该模块的属性上限；**拆除模块返还 30% 购置 + 80% 强化投入**（强化清空）。

## 模块强化

编辑器"已安装"区每个模块可花费储备**强化（⬆，最高 Lv5）**，不同类别效果不同：防御/躯干类（细胞壁、外骨骼、储能颗粒）每级 **+0.5 体积 且体积上限 +1**（强化 = 长个 + 扩仓，推高生命上限与体积里程碑）；移动/感官/武器类数值每级 +1；带物流节点的器官每级 **处理量 +25%**（器官自身属性）；光合器充能每级提升。代价：常驻消耗每级 **+15%**（推高代谢压力）。卸载重装清空强化（上限加成同步回落）。

**强化 = 属性，扩容 = 输送**：器官 ⬆ 强化只提升属性（攻击/护甲/速度/感知/体积上限，处理量随器官强化同步）；管线吞吐只在「内部物流」页选中管线「扩容（仅吞吐）」——两套系统互不占用。

## 器官槽位：上位替代（v0.6）

器官**不是无脑堆叠的加法，而是功能槽上的位次竞争**。同一槽位只能装一件，装更强的就得放弃旧的：

| 槽位 | 替代链 |
|------|--------|
| 口器位 | 口沟 → 基础口器 → 尖牙 |
| 防御位 | 细胞膜 → 细胞壁 → 外骨骼 |
| 运动位 | 鞭毛 → 纤毛丛 → 肌肉束 |
| 感官位 | 化学感毛 → 感光点 → 复眼 |
| 中枢位 | 细胞核 → 神经网 → 神经节 |
| 躯体位 | 细胞质躯干 → 多细胞聚合 |

**规则**（`src/systems/OrganSystem.ts`）：
- 安装高阶器官 → 自动顶掉同槽低阶（返还其购置与强化投入的对应份额）
- 安装低阶器官 → 若槽内已有更高位次则**拒绝**（不能退步）
- **先天器官不可拆**：口沟/细胞膜/细胞核/细胞质躯干 常驻体内，被高阶覆盖后以"覆盖"而非"拆除"的方式让位——属性、体积、消耗都不再计入（编辑器中显示为半透明划线）
- **可叠加件**：代谢处理器（原始胃/酶腺/真肠/心泵/鳃）、储能件（能量池/储能颗粒）、附加防御件（骨针触突/尾刺/三叶虫甲片）不占槽位，仍可自由叠加——它们是"配置"而非"形态位次"，全部互斥会堵死物流拓扑的组合空间
- **物流节点同步让位**：器官被顶替时，它携带的物流节点进入**隐退（dormant）**——不再参与吞吐计算、不再被自动接线、也不能手动拉线，也不在物流页显示（直接隐藏，不是灰显）。卸下高阶器官后原位复活并重新接线

> 这条规则是必需的：口沟与基础口器同为消化层 `source`，若两个节点并存，消化层就有**两条并行入口**。因为 `services()` 取的是各条链路的最大值，吞吐数字不会变——但玩家会看到一个永远无法拆除的幽灵入口，且它的支线永远占用连接数上限（4）。

这条设计让"改装"从数值加法变成**真实取舍**：想要外骨骼的 26 护甲，就得放弃细胞壁的速度加成与体积。

### 物流页底座 = 物种俯视图（v0.6）

内部物流页不再是抽象的矩形分区，而是**物种本体的俯视轮廓**（`src/ui/Anatomy.ts`）：

- 身体轮廓按当前体积实时绘制；外骨骼/细胞壁变色加厚，多细胞聚合轮廓带波浪，鞭毛/纤毛长在尾部
- 俯视朝向屏幕右方：**前方 = 右**（口器在此）· **背侧 = 上**（脑/神经在此）· **腹侧 = 下** · **尾部 = 左**
- 器官节点按解剖位自动摆位（口沟在最前、胃在腹腔、心偏前腹、脑在背侧、废物出口在尾端）
- 层色图例固定在左上角，替代外缘弧线（避免标签重叠）
- 隐退节点（被高阶器官替代的先天件）**完全不显示**，对应管线也不绘制

## 环境分区（v0.7）

世界不再是均匀的空旷海域——每个纪元有 3 个环境特征区域（`src/data/zones.json`），玩家所处位置决定代谢与战斗参数：

| 纪元 | 区域 | 特征 |
|------|------|------|
| 太古宙 | 热泉喷口 | BMR×1.5 产出×0.7（高温高代谢缺氧） |
| 太古宙 | 冷泉渗漏区 | BMR×0.6 有毒 1.5/s（节能但危险） |
| 太古宙 | 原始汤 | 食物×1.2（温和基准区） |
| 元古宙 | 富氧表层 | 产出×1.4 光合×2.0（蓝藻产氧） |
| 元古宙 | 硫化深沟 | 剧毒 3.0/s 低氧（有氧酶可中和 70%） |
| 元古宙 | 氧化过渡带 | 洋流推力（顺势加速） |
| 寒武纪 | 海藻森林 | 产出×1.3 视野×0.8（密林遮挡） |
| 寒武纪 | 浅水礁石区 | 食物×1.5 捕食者×1.3（伏击型） |
| 寒武纪 | 深海沟 | BMR×0.4 毒性 1.0/s 捕食者×1.5（深渊） |

**边界软过渡**：区域 radius×0.7 以内为完整效果，radius×0.7 到 radius 之间线性渐变，radius 以外为中性。多个区域重叠时取效果最强的那个。

**集成点**：`GameState.env` → `GameLoop` 每帧 `Env.compute()` → `Metab`（BMR/消化/光合）→ `World`（密度）→ `SenseOverlay`（视野）→ `WorldScene`（渲染）→ `HUD`（提示）

## 数值平衡（v0.6 基线）

全部数值集中在 `src/systems/RunState.ts` 的 `CONST`，并由 **`src/systems/BalanceProbe.ts`** 提供跨纪元 × 典型形态 × 强化度的观测口径。调参时运行 `npx vitest run tests/probe.test.ts` 打印完整报表。

**设计目标（已固化为 tests/balance.test.ts 的断言）**

| 维度 | 目标区间 | 说明 |
|------|----------|------|
| 代谢压力 | 正常构筑 15%~95% | 贪装无强化 >105% 被迫强化；强化后显著回落 |
| 击杀中立 TTK | 0.8~6.5s | 不秒杀也不拖沓 |
| 面对捕食者 | ≥2.5s 逃跑窗口 | 静站硬抗 ≤18s，逼玩家逃跑而非站桩 |
| 产出 P | 随纪元增长 | 管网随纪元升级（8→12→16）+ 后续纪元更强消化器官 |
| 经济 | 15 分钟买 5~15 件器官 | 难度梯度单调：温和 > 标准 > 恶劣 > 大灭绝 |
| 速度 | 0.6× ~ 2.2× 基准 | 堆防御件带负速度但不跌破下限；杜绝速度断层 |
| 强化 | Lv5 ≈ 6 倍购置价 | 长期投资，与"买新件"形成取舍 |

**压力档位（v0.6 放宽）**：< 90% 健康 / 90~110% 黄色（效率 85%） / 110~130% 橙色（效率 60%、速度 80%） / > 130% 红色（效率 30%、充能停止）。正常构筑稳在健康区，只有真正贪装或缺代谢器官时才告警。

**核心公式**

```
代谢产出  P = (2.0 + 消化吞吐 × 1.1) × (1 + 代谢类强化 × 12%)
总消耗    R = BMR(0.55 + 体积×0.026) + 移动 + 感知 + 器官常驻
代谢压力  = R / P        （<90% 健康 / 110% 黄 / 130% 橙 / >130% 红）
消化速率  = (1.0 + 吞吐 × 0.25) × 消化效率
管道容量  = 8 + 4 × 纪元序号   （纪元推进时自动升级，扩容等级保留）
生命值    = 30 + 体积 × 6 + 躯干加成
生长储备  = 摄入营养 × 4% × 难度growthMult + 击杀 × 4⬢
```

**纪元产出曲线**：太古宙 P≈10.8（吞吐 8）→ 强化后 21.2（吞吐 12）→ 寒武纪强化后 21.2（吞吐 12，真肠 24 受口沟源限制）。**口沟（源节点）是消化瓶颈**，强化口沟是提高吞吐最直接的路径——这是设计上的有意的取舍点。

## 安全设计与检查

线上版本在 2026-11-04 完成安全加固，完整记录见工作区 `安全检查报告.md`。

| 项 | 实现 |
|----|------|
| 内容安全策略 | `vite.config.ts` 的 `cspMeta()` 仅在生产构建把 CSP 注入 `<head>` 最前；`script-src 'self'` 禁止内联脚本与行内事件处理器；`object-src` / `base-uri` / `form-action` 收紧 |
| 引用策略 | `no-referrer` |
| 开发调试桥 | `window.SFW` 仅在 `import.meta.env.DEV` 下挂载，生产构建静态消除 |
| HTML 输出 | `src/core/escape.ts` 统一转义，UI 层承载文本的动态插值均经 `esc()` |
| 存档安全 | `SaveSystem` 白名单过滤记忆 id、校验代数/版本/快照数量、逐字段清洗统计；`newRun` 跳过未知 id |
| 依赖与发布 | Vite 8.3.5 / Vitest 5.1.0（`npm audit` 0 漏洞）；CI 固定 Action 提交 SHA，执行 lint / test / build 门禁 |
| 仓库设置 | 密钥扫描、推送保护、Dependabot 安全更新、`main` 分支保护均已开启 |

`style-src` 保留 `'unsafe-inline'`：DOM UI 依赖行内 style 属性与 CSSOM 动态设置，该指令不赋予脚本执行能力。

**平台限制**：GitHub Pages 不支持自定义响应头，`X-Content-Type-Options` / `X-Frame-Options` / `Permissions-Policy` 无法在该平台下发。仓库提供 `public/_headers`（Cloudflare Pages / Netlify 格式），迁移到支持自定义响应头的托管平台后即时生效。漏洞披露方式见 `SECURITY.md`，开源协议见 `LICENSE`。
